I run A/B tests for clients across a pile of different platforms, and every one of them reports results its own way. Figuring out which tests were actually ready to call meant opening six tabs and doing a lot of squinting.

So I built a kitchen. A/B Test Kitchen pulls every test from Optimizely, Convert, VWO, Intelligems, Shoplift and Shopify Rollouts into one place, recomputes the stats from the raw counts, and sorts each test into Draft, Running, Ready or Called. Same rules for every client and every platform: at least two weeks, plus 90% confidence or the full planned sample.

My favorite part is the peeking switch. Checking results too early is how you end up calling a false winner, so with peeking off, the numbers stay blurred until the test has earned them. You can still click to peek at a single test. It's a speed bump, not a wall.

Right now it runs on fictional clients and simulated traffic, but the connectors are built against each platform's real API, so plugging in keys is the next step, not a rewrite. Next up: an MCP server so Claude can answer "what's ready to call?" and, eventually, start and stop tests right from the dashboard.
